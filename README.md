# SHREENIKETAN Child Care & Education

A premium, modern, and responsive website for **SHREENIKETAN Child Care & Education Centre**, built with React, Vite, and Tailwind CSS. The site is designed to reflect excellence in early childhood education while providing a seamless user experience for parents.

## 🚀 Live Demo
The project is deployed via GitHub Pages:  
[View Live Site](https://onig.github.io/SHREENIKETANSCHOOL/)

## ✨ Features
- **Modern Design**: Premium aesthetics with a clean, child-friendly color palette.
- **NEP 2020 Aligned**: Content highlighting compliance with the latest educational guidelines.
- **Responsive Layout**: Optimized for desktop, tablets, and mobile devices.
- **Interactive Components**: 
  - Smooth scrolling navigation.
  - Admissions popup enquiry form.
  - Floating WhatsApp contact button.
  - "Dr. Tips" corner for expert guidance.
  - Gallery and testimonials sections.
- **Performance Optimized**: Built with Vite for ultra-fast loading and smooth animations.

## 🛠 Tech Stack
- **Framework**: [React](https://reactjs.org/)
- **Bundler**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Deployment**: GitHub Actions + GitHub Pages

## 📦 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/onig/SHREENIKETANSCHOOL.git
   cd SHREENIKETANSCHOOL
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

### Building for Production
To create a production-ready build:
```bash
npm run build
```
The output will be in the `dist/` directory.
